# Open questions — places where spec v3.0 is silent or inconsistent

Found while writing CLAUDE.md (MFW-3). Each must be decided (by the product owner, or by the ticket's
lead with the decision written in the PR) **before** the listed ticket is implemented. Do not guess silently.

| 1 | How does an owner prove ownership to read `private_wish_text`? §5 says the client sends `owner_token`; backlog 2.1 says only the SHA-256 hash ever leaves the device — but a hash sent as-is is itself a bearer secret. | §5, backlog 2.1 | MFW-12 (2.2), MFW-31 (7.2) — Decided in MFW-12: the device keeps the raw DeviceOwnerToken in LocalStorage; the server stores only SHA-256(token).
