# 6.5 Loop 5: Loy Krathong Ritual, River Spline Movement & Growing River Zones

### Task 5.1: “Make & Release” Ritual Interaction

- สร้างฉากท่าน้ำสำหรับปล่อยกระทง: แสดง Preview กระทงของตัวเองก่อนวาง เมื่อผู้ใช้ลากกระทงลงสู่ผิวน้ำ (หรือกดปุ่ม “ปล่อยกระทง”) จะเกิดวงน้ำกระเพื่อม (Ripple) แสงเทียนสว่างขึ้น และกระทงค่อยๆ เคลื่อนออกสู่สายน้ำส่วนรวม

### Task 5.2: Deterministic Spline River Flow

- สร้างเส้นทางสายน้ำด้วย Spline Curve ให้กระทงทุกชิ้นเคลื่อนที่ช้าๆ ในพื้นที่ที่กำหนด พร้อมแอนิเมชันลอยโคลงเคลงเบาๆ (Procedural Bobbing)
- คำนวณตำแหน่งจาก SplinePathCoord ตามเวลาจริง เพื่อให้ระบบ “ค้นหาของฉัน” ติดตามตำแหน่งปัจจุบันของกระทงได้ตลอดเวลา

### Task 5.3: Growing River World & Zone Pagination

- จำกัดจำนวนกระทงที่แสดงพร้อมกันใน 1 โซนคุ้งน้ำ (เช่น 80 ชิ้น)
- เมื่อมีผู้ร่วมเล่นเพิ่มขึ้น ระบบจะเปิด โซนคุ้งน้ำใหม่ (Zone 2, Zone 3, ...) ต่อเนื่องไปตามลำน้ำ แทนการโหลดกระทงทั้งหมดมาอัดแน่นในฉากเดียว
