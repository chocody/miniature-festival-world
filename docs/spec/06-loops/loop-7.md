# 6.7 Loop 7: “ค้นหาของฉัน” (Find My Krathong) & Cross-Zone Tracking

### Task 7.1: My Creations Drawer & Real-time Position Tracker

- สร้างปุ่ม “ค้นหาของฉัน” ที่แสดงรายการกระทงที่ผู้ใช้เคยสร้างไว้ในอุปกรณ์นี้
- เมื่อผู้ใช้กดเลือกกระทง:
  1. ตรวจสอบ zone_id ของกระทงชิ้นนั้น หากอยู่คนละโซนกับที่กำลังดูอยู่ ให้โหลดโซนคุ้งน้ำนั้นขึ้นมาก่อน (`await loadZone(zoneId)`)
  2. คำนวณพิกัดปัจจุบันของกระทงที่กำลังเคลื่อนที่บนสายน้ำจาก SplinePathCoord
  3. เคลื่อนกล้องไปยังตำแหน่งปัจจุบันของกระทง หมุนหามุมที่มองเห็นชัด และเล่นเอฟเฟกต์ Highlight ติดตามตัวกระทง

### Task 7.2: Anonymous Wish Reader & Owner Private View

- หากแตะกระทงของคนอื่น จะเห็นเฉพาะข้อความที่เจ้าของเปิดเป็นสาธารณะ (ไม่มีชื่อหรือโปรไฟล์)
- หากเป็นกระทงของตัวเอง (ตรวจสอบผ่าน DeviceOwnerToken) จะสามารถเปิดอ่านข้อความที่ตั้งค่าเป็น “ส่วนตัว” ของตัวเองได้
