# 6.3 Loop 3: Minimal Toy-like 3D Viewport & Mobile Input Separation

### Task 3.1: Toy-like 3D LookDev (Night River Ambience)

- ตั้งค่ากล้อง Orthographic (มุมมองโลกจิ๋ว), แสงนุ่มยามค่ำคืน, แสงเทียนสีอุ่น และวัสดุ Matte Material สีเรียบ มุมมนเล็กน้อย ไม่เงาวาว

### Task 3.2: Input Separator (แยกหมุนกล้อง vs วางของบนมือถือ)

- แยกโหมดควบคุมชัดเจนเพื่อป้องกันการแตะหรือลากผิดบนมือถือ:
  - โหมด CUSTOMIZE: ลากเพื่อหมุนดูกระทงรอบด้าน + ซูมเข้าออก
  - โหมด RITUAL_RELEASE: ล็อกมุมกล้องที่ท่าน้ำเพื่อให้ผู้ใช้ลากกระทงลงแม่น้ำ (หรือกดปุ่มปล่อยกระทงสำหรับผู้ไม่สะดวกใช้ Gesture)
  - โหมด WORLD_EXPLORE: ลากเพื่อเลื่อน/หมุนดูคุ้งน้ำ แตะสั้นเพื่อ Interact กับน้ำ ไฟริมฝั่งหรือกระทง

### Task 3.3: Camera Fly-To & Highlight Controller

- สร้างฟังก์ชันเคลื่อนกล้องไปยังพิกัดเป้าหมายอย่างนุ่มนวล หมุนหามุมที่มองเห็นชัดเจน และแสดงเอฟเฟกต์วงแหวนสว่าง (Highlight) รอบชิ้นงาน
