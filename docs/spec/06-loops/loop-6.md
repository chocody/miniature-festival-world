# 6.6 Loop 6: Loy Krathong Scene Environment & Interactive Gimmicks

### Task 6.1: Low-Poly Night River Environment

- จัดวางฉากหลังรายละเอียดต่ำแต่มีเสน่ห์: บ้านไม้ริมฝั่ง ต้นไม้ โคมไฟริมน้ำ และท่าน้ำ โดยคุมโทนให้กระทงที่ Interact ได้มีความโดดเด่นและสังเกตง่ายที่สุด

### Task 6.2: Interactive Scene Gimmicks & Object Pool

- แตะผิวน้ำ: เกิดวงน้ำกระเพื่อม (Water Ripple) โดยจำกัดจำนวน Ripple ที่แสดงพร้อมกันด้วย Object Pool
- แตะโคมไฟ/ไฟริมฝั่ง: ไฟสว่างขึ้นหรือกะพริบอบอุ่นพร้อมแอนิเมชันเด้งเล็กน้อย
- แตะกระทงในแม่น้ำ: กระทงเด้งตอบสนองเบาๆ และเปิดการ์ดแสดงรูปลักษณ์พร้อมคำอธิษฐานสาธารณะแบบ Anonymous
